# 焦点流程实验台（focus-flow-lab）

条件表单里，某些控件随开关出现/消失后，键盘用户可能掉进只能在局部跳转的**焦点陷阱**——只看默认状态的 Tab 顺序根本发现不了。本页把焦点流程建模为状态搜索问题：

- **状态** = （焦点节点， 开关位集）；所有开关初始为关。
- 每个节点的**可见条件**是若干开关字面量的合取（`[["lamp", false], ...]`）。
- 每个节点可定义 **Tab / Shift+Tab / 激活** 三个动作的目标；激活可顺带**翻转一个开关**。
- 动作执行后若目标节点隐藏，则该动作**不可走**（失效边）。

搜索两种见证，同长度按 **Tab < Shift+Tab < 激活** 裁决：

1. **最短按键序列**：从入口到目标节点；
2. **最短陷阱前缀**：从入口可达、但执行完后再也无法抵达目标的最短序列（空序列表示入口本身即陷阱）。

## 单边重定向预览

找到陷阱后，可进一步预览“只改一条键盘跳转”能否修复全图（仅 ≤ 12 节点、≤ 4 开关的图；导入与搜索上限不变）：

- **候选**：把一条已定义的 Tab / Shift+Tab / 激活动作的目标改为不同于旧目标的另一已声明节点，激活动作原有的翻转开关不变；
- **安全判定**：对每个候选重新展开焦点×开关状态图，只要还存在入口可达却无法抵达目标的状态就淘汰该候选；
- 多个安全候选按 **源节点 id → 动作优先级 → 目标 id** 取最小，返回修改前后最短到达见证（原先不可达时为 `null`）及被消除的陷阱见证；
- 原图已无陷阱返回 `ALREADY_SAFE`，无解返回 `NO_SINGLE_REDIRECT`；
- 预览是纯计算，不修改当前导入图与回放；点击“应用此重定向”后才替换图、同步导入框文本并清空旧见证。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest：固定场景 + 随机小状态图与独立 BFS 对拍
npm run build      # 生产构建
```

或用 Compose 直接起 focus 页面（http://localhost:5173）：

```bash
docker compose up --build
```

## 导入格式

```json
{
  "nodes": ["gate", "hall", "vault", "cell", "mirror"],   // 2..40 个唯一节点
  "switches": ["lamp"],                                   // 0..8 个开关
  "entry": "gate",                                        // 唯一入口（初始必须可见）
  "target": "vault",                                      // 唯一目标
  "conditions": { "vault": [["lamp", false]] },           // 可见条件：字面量合取
  "edges": {
    "hall": {
      "tab": "vault",
      "shiftTab": "gate",
      "activate": { "to": "cell", "flip": "lamp" }        // 激活可翻转一个开关
    }
  }
}
```

非法导入会列出全部错误并**保留当前图**。页面支持逐键回放见证序列，并以红色虚线高亮当前开关位下的失效边、绿色高亮走过的边。

## 测试

`src/lib/search.test.ts` 包含：

- 内置示例的精确断言（最短见证 `Tab, Tab`；陷阱前缀 `Tab, 激活`）；
- **切换后节点消失**的场景：翻转开关使目标/源节点隐藏，验证失效边不被搜索采用；
- 裁决顺序、导入校验（非法导入不抛异常、不产出部分图）；
- 200 个随机小状态图（2–6 节点、0–3 开关）与测试内**独立实现**（反向松弛求距 + 贪心取路、字符串状态 BFS）对拍。

`src/lib/redirect.test.ts` 包含：

- 固定场景：**切换后目标隐藏**（内置示例的最小安全候选）、**空陷阱前缀**（入口本身即陷阱、原先不可达时 `before` 为 `null`）、**重定向制造新陷阱**的候选被淘汰、`NO_SINGLE_REDIRECT` / `ALREADY_SAFE` / 预览上限（12 节点 / 4 开关）；
- 200 个随机小图上**独立枚举所有单边替换**，逐一比对安全判定，并对预览结果（状态、候选、修改前后见证、被消除陷阱）整体对拍；
- `graphToJson` 往返一致（应用重定向后同步导入框的前提）。
